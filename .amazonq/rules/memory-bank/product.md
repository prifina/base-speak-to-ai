# Product Overview

## Project Purpose
New Router Base App is a Next.js-based web application that serves as a foundation for building modern React applications with authentication, routing, and UI components. It provides a complete starter template with AWS Amplify integration for authentication and Chakra UI for the component system.

## Key Features
- **Authentication System**: AWS Amplify-based authentication with JWT token handling
- **Modern UI Framework**: Chakra UI v3 integration with custom theming and components
- **Routing Architecture**: Next.js App Router with protected routes and middleware
- **API Integration**: RESTful API endpoints for user management and configuration
- **State Management**: Zustand for client-side state management
- **Development Tools**: ESLint configuration and development server setup

## Target Users
- **Frontend Developers**: Building React applications with authentication requirements
- **Full-Stack Teams**: Needing a solid foundation for web applications with AWS integration
- **Startups/Projects**: Requiring rapid development with modern web technologies
- **Enterprise Teams**: Building scalable web applications with proper authentication flows

## Use Cases
- **Web Application Starter**: Foundation for new React/Next.js projects
- **Authentication-First Apps**: Applications requiring user login and protected routes
- **AWS-Integrated Solutions**: Projects leveraging AWS services for backend functionality
- **Component Library Development**: Building reusable UI components with Chakra UI
- **Rapid Prototyping**: Quick setup for testing ideas and concepts
